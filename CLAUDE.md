# CLAUDE.md

`@bounceapp/react-native-paypal`: an Expo module that bridges the PayPal (Braintree) iOS and Android SDKs. A Swift module (`ios/`), a Kotlin module (`android/`), a TypeScript wrapper (`src/`) and an Expo config plugin (`plugin/`), with an Expo example app in `example/`, a pnpm workspace package.

## Commands (pnpm only)

Node comes from `.tool-versions` (`mise install`); run `corepack enable` once so `pnpm` is the pinned version.

- `pnpm install`: install dependencies and build `lib/`.
- `pnpm typecheck`: `tsc`.
- `pnpm lint`: oxlint (type-aware) and `oxfmt --check`. `pnpm lint:fix` autofixes and formats.
- `pnpm lint:kotlin`: detekt on `android/src`. Needs a JDK on the path or `JAVA_HOME`.
- `pnpm test`: Jest (`--passWithNoTests`). One file: `pnpm test plugin/__tests__/withPaypal.test.js`; one test: `pnpm test -t "<name>"`.
- `pnpm run docs`: typedoc into `docs/`. Spell out `run`: `pnpm docs` is a built-in pnpm command.
- `pnpm example start|ios|android|web`: run the example app (`start` is `expo start --dev-client`; `ios` and `android` are `expo run:ios` and `expo run:android`).

## Testing changes

- Jest covers only the config plugin (`plugin/__tests__/withPaypal.test.js`). The Swift and Kotlin code has no automated tests.
- The example app is the check for iOS and Android. It needs a development build, because the native module is not in Expo Go: `pnpm example ios` or `pnpm example android` builds and installs one, and `pnpm example start` serves JS to it. Metro bundles the library from `src/`, so edits there reload without a rebuild; native changes need a new `ios` or `android` run.
- PayPal does not work on web. `pnpm example web` only checks that importing the package does not break a web bundle (see the comment in `.github/workflows/web.yml`).

## Notes

- `src/Paypal.ts` is the native implementation, `src/Paypal.web.ts` is a web stub, and `src/types.ts` holds the shared types. `src/index.ts`, `src/types.ts`, `plugin/` and `app.plugin.js` are public API: do not change them without discussing it.
- `lib/` is build output (`bob build`) and `docs/` is typedoc output. Both are git-ignored; do not edit them by hand. `example/ios` and `example/android` are generated by `expo run:*` and git-ignored too.
- Leave `LICENSE` untouched.
- The Braintree SDK versions live in `react-native-paypal.podspec` (iOS) and `android/build.gradle` (Android).
- Git hooks come from `lefthook.yml`: pre-commit runs oxlint and oxfmt on staged files, then `tsc` and Jest; commit-msg runs commitlint.
- Commits follow Conventional Commits (`@commitlint/config-conventional`). Allowed types: `build`, `chore`, `ci`, `docs`, `feat`, `fix`, `perf`, `refactor`, `revert`, `style`, `test`.
